# DSH Server Monitor Sidebar

A Web sidebar footer action that opens a compact status panel backed by the Host monitor status endpoint.

## Model Experience

This package has no direct model-facing behavior. It displays current server observations and active alerts produced by the Host monitor service.

## Known Limitations and Deferred Work

The panel currently refreshes every 30 seconds while open. Server configuration, historical charts, alert acknowledgement, and manual check controls are deferred.
